## APIs Útiles para Contexto Macro (Trading de Oro)

El precio del oro (XAUUSD) se ve afectado por:

| Factor | API Recomendada |
|--------|-----------------|
| Inflación / datos macro EEUU | FRED (Federal Reserve) |
| Índice del dólar (DXY) | Fixer, 1Forge, Exchangerate.host |
| Tasas de interés | FRED, Econdb |
| Noticias geopolíticas | MarketAux, NewsData, The Guardian |
| Precio del oro directo | Alpha Vantage, Twelve Data, Finnhub |
| Sentimiento de mercado | WallstreetBets, MarketAux |
| Datos de cripto (correlación) | CoinGecko, CryptoCompare |
